---
title: POST /api/price
description: Price a European option using Black-Scholes, Bachelier-OU, Monte Carlo, or Finite Difference
---

## Endpoint
POST /api/price

## Authentication

All requests require `X-API-Key` header.

## Request body

| Parameter | Type | Required | Description |
|---|---|---|---|
| `S` | number | ✓ | Current spot price |
| `K` | number | ✓ | Strike price |
| `T` | number | ✓ | Time to maturity (years) |
| `r` | number | ✓ | Risk-free rate (decimal, e.g. 0.05) |
| `sigma` | number | ✓ | Volatility (% for BS/MC/FDM, absolute €/tonne for Bachelier) |
| `isCall` | boolean | | true = call (default), false = put |
| `model` | string | | `bs` (default), `bachelier`, `mc`, `fdm` |
| `kappa` | number | | OU mean-reversion speed (Bachelier only, default 1.0) |
| `theta` | number | | OU long-run equilibrium (Bachelier only, default 0.9×S) |
| `N` | number | | Monte Carlo paths (MC only, default 2000) |

## Models

<AccordionGroup>
  <Accordion title="Black-Scholes (default)">
    Closed-form analytical solution. Returns price, all 5 Greeks,
    and cross-checks from Monte Carlo and Crank-Nicolson FDM.

```bash
    curl -X POST .../api/price \
      -H "X-API-Key: key" \
      -d '{"S":100,"K":100,"T":1,"r":0.05,"sigma":0.2}'
```
  </Accordion>

  <Accordion title="Bachelier-OU (carbon options)">
    Closed-form Bachelier model for options on mean-reverting
    Ornstein-Uhlenbeck price processes. The correct model for
    EU ETS EUA options. Requires kappa and theta parameters.

```bash
    curl -X POST .../api/price \
      -H "X-API-Key: key" \
      -d '{"model":"bachelier","S":65,"K":65,"T":1,"r":0.04,
           "sigma":15,"kappa":1.0,"theta":60}'
```
  </Accordion>

  <Accordion title="Monte Carlo GBM">
    Statistical estimation via 2,000 GBM path simulations.
    Returns price with 95% confidence interval.

```bash
    curl -X POST .../api/price \
      -H "X-API-Key: key" \
      -d '{"model":"mc","S":100,"K":100,"T":1,"r":0.05,"sigma":0.2}'
```
  </Accordion>

  <Accordion title="Finite Difference (Crank-Nicolson)">
    Numerical PDE solver. Unconditionally stable.
    Returns price with Black-Scholes cross-check.

```bash
    curl -X POST .../api/price \
      -H "X-API-Key: key" \
      -d '{"model":"fdm","S":100,"K":100,"T":1,"r":0.05,"sigma":0.2}'
```
  </Accordion>
</AccordionGroup>
