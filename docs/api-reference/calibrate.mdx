## Endpoint
POST /api/calibrate

Estimates κ, θ, σ from observed price data using OLS regression on
the discrete AR(1) representation of the OU process.

## Request body

| Parameter | Type | Required | Description |
|---|---|---|---|
| `prices` | number[] | | Historical price series. Omit to use built-in 48-month EUA dataset |
| `dt` | number | | Time step in years (default 1/12 for monthly data) |

## Example — use built-in EUA dataset

```bash
curl -X POST https://quant-carbon.shoumyadeep309.workers.dev/api/calibrate \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-key" \
  -d '{}'
```

## Example — supply your own price series

```bash
curl -X POST https://quant-carbon.shoumyadeep309.workers.dev/api/calibrate \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-key" \
  -d '{"prices": [55.2, 58.4, 61.1, 63.7, 60.2, 58.9, 62.4], "dt": 0.0833}'
```

## The mathematics

The OU process in discrete time is a linear AR(1) model:
S(t+dt) = α + β·S(t) + ε

OLS recovers α and β. Parameters follow algebraically:
β  = e^{−κ·dt}     →  κ = −ln(β)/dt
α  = θ·(1−β)       →  θ = α/(1−β)
σ² = var(ε)·2κ/(1−β²)
